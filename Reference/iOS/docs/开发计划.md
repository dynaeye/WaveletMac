# WaveletRadio 开发计划

产品基线：`../波粒-iOS产品设计纲要.md`，2026-09-28 启动。

## 最新界面基线（2026-09-28）

按用户提供并持续更新的 `../exports/00-flow.png` 与页面设计图执行：封面 → 首页；首页左划/电台列表进入电台列表页，右划/设置进入设置，上划/点击数码屏进入播放状态；各子页面提供返回。电台列表页分为「我的收藏」与「检索」，原搜索、四级筛选及分组列表归入检索；首页与列表行提供同步的收藏五角星，本机持久化并按最近收藏排序。此导航替代原计划的三个底部主标签和首页地区快捷列表。自动播放改为用户主动开启的持久化设置，默认关闭；进入首页时才执行。其余播放与数据验收要求继续有效。

视觉使用米色 #EDE7DA、卡片 #F8F4EB、深林绿 #2E3A2E、琥珀 #EAB96A、墨色 #28281F、分隔线 #DED6C6。字体资源及许可证随 App 打包，页面截图见 `docs/screenshots`。

## 项目结构

- `WaveletRadio/Models.swift`：电台、线路、地区、目录、搜索排序规则。
- `WaveletRadio/RadioStore.swift`：本机常听、上次选择、应用状态。
- `WaveletRadio/PlaybackEngine.swift`：单一 AVPlayer、状态、重试、系统控制、睡眠截止时间。
- `WaveletRadio/ContentView.swift`：收音机、发现、设置和现在播放。
- `WaveletRadio/Resources`：版本化 JSON 目录。
- `scripts`：网页数据迁移与规则验证。
- `docs`：开发进度、验收与接续说明。

## 数据迁移

读取网页 `dist/stations.js` 的 JSON 赋值，不执行网页脚本。保留原始电台 ID、别名、地区、省市、城市、类型、语言、来源及线路测试时间。同台按 URL 去重，只接受 web=true、有测试时间、HTTPS 且为 HLS 或 AAC/MP3 的线路。明确剔除 external 电台。

候选集仅供 Debug 测试。Release 使用独立 `stations.json`，必须通过 iPhone 真机验证清单筛选；不将网页验证冒充原生验证。真机记录需要包含线路 URL、设备、系统、测试时间、实际播放时长和结论。初始正式目录为空。

常听只累计主动选台；自动重试、暂停与恢复不累计。每区前四按次数降序再按拼音。目录按地区、分组、台名拼音排序；大陆全国/央广、北京、上海优先，电视央视、香港优先。繁简体归一化用于搜索，保留原名称用于显示。

## 实施阶段

1. 数据和界面：迁移脚本、目录模型、搜索筛选、本机常听、三个标签、全局迷你播放器。
2. 播放基础：单一播放器、六种状态、最多三条线路尝试、手动切线、无进度超时、断网不自动恢复、后台与锁屏控制、睡眠计时。
3. 验收：规则测试、模拟器界面检查、iPhone 真机代表线路长时间播放、后台/睡眠/中断/耳机/网络恢复验证、VoiceOver 与动态字号；验证后生成正式目录。

每次工作结束更新 `docs/开发进度.md`，记录已完成、验证证据、未完成和下次入口。尚未完成真机验收不能宣称首发完成。
