## 2026-10-20 本地媒体：SMB、UPnP/DLNA 与本机文件夹

- 主界面底部新增“本地媒体”入口，打开独立媒体库。媒体库左侧按 UPnP、SMB、本地文件夹分组管理媒体源，右侧提供面包屑导航、当前目录搜索、文件夹/音频列表、双击进入或播放、播放全部与返回上级；底部播放条显示当前本地曲目、封面占位、进度拖曳和上一首/播放/下一首。

- UPnP 实现：SSDP `M-SEARCH` 发现（同时搜索 MediaServer 与 `ssdp:all`，遍历所有活动 IPv4 接口发送）、设备描述解析（含 `URLBase`、嵌套设备与相对 `controlURL`）、ContentDirectory `Browse` SOAP 请求、DIDL-Lite 容器/音频资源解析、音频 MIME 选择、相对资源地址解析、分页与最多 5,000 项上限。发现到的服务器会保存到本机媒体源列表，也可手动添加设备描述地址。
- SMB 实现：使用系统 `NetFS` 客户端按需挂载 `smb://host/share`，挂载点位于 `Application Support/Wavelet/MediaMounts`，默认不显示于 Finder；支持访客、用户名/密码、端口和 IPv6 主机写法。密码只在“记住密码”时写入 macOS 钥匙串；应用退出和删除媒体源时卸载，启动时清理遗留挂载。共享内浏览只显示文件夹与受支持的音频扩展名。
- 本机文件夹实现：通过系统文件面板选择，保存安全作用域书签并持久化；重新打开时恢复书签访问。可识别的音频扩展名覆盖 MP3、M4A/ALAC、AAC、FLAC、WAV、AIFF、OGG/Opus、WMA、APE、M4B、CAF、DSF/DFF 等；实际解码能力取决于系统 AVFoundation。
- 播放引擎扩展：新增本地队列、曲目索引、播放位置/时长、拖曳定位、自动下一首、队尾停止与手动循环、失败自动跳过、`Now Playing` 元数据（标题/艺术家/专辑/时长/进度）和本地网络源断网失败处理；本地文件夹播放不受断网影响。电台与本地播放互斥，启动时仍只恢复上次电台且不自动播放。
