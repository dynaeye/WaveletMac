# Wavelet Mac 个人电台使用与隐私说明

Wavelet Mac 是个人网络电台播放器，不预置公共电台目录。首次打开时电台列表为空。你可以手动添加，也可以导入自己准备的 JSON 文件；支持的 JSON 单次最多 10,000 台、10 MiB，导入时按播放 URL 去重。完整格式可包含多条播放线路，并可在 Wavelet iPhone/iPad 与 Mac 之间导入、导出。

个人电台、收藏和应用偏好保存在当前 Mac 的本地用户目录。应用不提供账号、开发者云同步、广告或分析服务。迁移旧版时应用会在本地保留一次旧偏好快照，然后以空目录启动；旧版内置目录不会成为新版本的电台来源。

本地 JSON 只在用户通过系统文件面板选择后读取。网络 JSON 只在用户输入 HTTPS 地址并主动开始导入后下载，单次超时 30 秒并受 10 MiB 上限约束；下载可以取消，失败或取消不会部分修改目录。播放时应用会连接用户添加的电台音源，具体音频请求、日志与数据处理由相应音源服务方决定。

导出的 JSON 包含全部个人电台、稳定 ID 和播放线路，不包含收藏、播放历史、音量、主题、语言等设置，也不包含本地媒体源、SMB 凭据或钥匙串内容。请妥善保管导出文件；通过其他服务分享后，其副本和处理方式由接收方及该服务决定。应用中删除单台电台或清空目录，会移除本机对应目录、收藏及线路偏好并停止相关播放；不会删除用户另存或分享的导出文件。

仅添加你有权收听和处理的音源。开发者：Kai。

## 本地媒体（SMB、UPnP/DLNA 与本机文件夹）

主界面的“本地媒体”会打开独立媒体库。只有在你打开媒体库或主动扫描后，应用才会通过本地网络发现 UPnP/DLNA 设备；发现使用 SSDP 组播，读取设备的描述文档并列出其内容目录。首次使用时 macOS 会询问是否允许 Wavelet 访问本地网络；如果拒绝，可以手动添加设备描述地址，或在“系统设置 › 隐私与安全性 › 本地网络”中重新允许。

添加 SMB 服务器时，应用使用 macOS 系统 SMB 客户端按需挂载你指定的共享。挂载点位于本机 `~/Library/Application Support/Wavelet/MediaMounts`，退出应用时会尝试卸载；共享中的音频由系统播放器直接读取，不会复制到其他位置。用户名和共享名保存在本机媒体源配置中；密码仅在你选择“记住密码”时写入 macOS 钥匙串，未选择时只保留在当前运行的进程内。应用不会把 SMB 凭据写入电台 JSON 或导出文件。

本机文件夹仅在你通过系统文件面板选择后访问；应用保存书签以便下次继续浏览，音频同样在本机播放。UPnP/DLNA 的浏览与播放请求只发送到你选择的局域网设备，SMB 文件只在你添加的共享内读取。本地媒体不会上传到开发者服务器，也不包含账号、广告或分析服务。请仅添加你有权访问和播放的媒体源。
