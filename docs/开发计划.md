# WaveletMac 开发计划

## 目标

基于 WaveletRadio iOS 1.0 已验证的目录、翻译、搜索、收藏、常听与播放策略，开发原生 macOS SwiftUI 版本。Mac 版保持 Wavelet 品牌和数据语义，不照搬 iPhone/iPad 界面。

## 阶段

1. 创建 macOS 15+ SwiftUI 工程，确定 App 名称、Bundle ID、签名与最低系统。
2. 接入 `Shared/Models.swift`、电台目录、六语翻译、Logo 和字体，建立数据解码测试。
3. 实现 macOS 专用播放引擎，验证 AVPlayer、缓冲/失败状态、线路重试、音频设备切换和睡眠唤醒。
4. 迁移 RadioStore，保留搜索、筛选、收藏、常听、上次电台、语言和主题持久化。
5. 保持单实例收音机主界面，收藏、目录和设置使用底部独立抽屉；补充菜单栏播放、窗口恢复、最小化与辅助功能。
6. 在真实 Mac 上逐台验证播放，将合格线路写入 `docs/native-validation.json`，生成 Mac Release 目录。
7. 完成深色模式、大字号、VoiceOver、单实例窗口/菜单栏评估、打包和发布验收。

## 原则

- 候选目录不等于正式目录；Release 只收录 Mac 原生验证通过的线路。
- 播放状态必须反映真实 AVPlayer 进度，不以点击播放代替成功判定。
- 默认不自动发声；断网恢复、启动和唤醒后不得意外播放。
- Mac 版取消 iOS 的随机金句功能，不保留金句翻译和资源。
- 优先共享数据和纯逻辑，播放会话、窗口和交互使用 macOS 原生实现。
