# Wavelet

Wavelet 是一款轻巧的 macOS 网络收音机，让你从一个简洁的桌面界面收听不同地区的电台。

## 功能

- 浏览和搜索电台目录，按地区、城市和分类筛选电台。
- 收听电台并切换可用播放线路；支持播放、暂停和音量调节。
- 收藏常听电台，并设置睡眠定时。
- 从 macOS 菜单栏查看当前电台并控制播放。
- 选择浅色、深色或跟随系统外观；界面提供简体中文、繁體中文、English、日本語、한국어、ไทย、Español 和 العربية。
- 默认不会在启动时自动播放，可在设置中更改。

## 版本与系统要求

当前版本：1.0。支持 macOS 15 或更新版本，并提供 Apple 芯片与 Intel Mac 通用版本。

## 下载与安装

Wavelet 1.0 已完成 Developer ID 签名和 Apple 公证。可从 [GitHub Releases 下载 `Wavelet-1.0.dmg`](https://github.com/dynaeye/WaveletMac/releases/download/v1.0/Wavelet-1.0.dmg)：打开 DMG，将 Wavelet 拖入“应用程序”文件夹，然后从“应用程序”中启动。
