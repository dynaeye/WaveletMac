# Wavelet

## English

Wavelet is an internet radio app dedicated to Chinese-language radio stations. It offers more than 1,500 Chinese broadcasts from different regions.

### Features

- Browse and search the station directory, filtering stations by region, city, and category.
- Listen to stations and switch between available streams; play, pause, and volume controls are supported.
- Add the stations you listen to often to Favorites, and set a sleep timer.
- View the current station and control playback from the macOS menu bar.
- Choose Light, Dark, or System appearance; the interface is available in Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Thai, Spanish, and Arabic.
- By default, playback does not start automatically at launch; you can change this in Settings.

### Version and System Requirements

Current version: 1.0. Supports macOS 15 or later, with a universal build for both Apple silicon and Intel Macs.

### Download and Installation

Wavelet 1.0 is signed with a Developer ID and notarized by Apple. Download [`Wavelet-1.0.dmg` from GitHub Releases](https://github.com/dynaeye/WaveletMac/releases/download/v1.0/Wavelet-1.0.dmg).

### Feedback

## Español

Wavelet es una radio por internet dedicada a las emisoras en chino. Permite escuchar más de 1500 emisoras de distintas regiones.

### Funciones

- Explora y busca en el directorio de emisoras, con filtros por región, ciudad y categoría.
- Escucha emisoras y cambia entre las fuentes de reproducción disponibles; incluye reproducción, pausa y ajuste de volumen.
- Guarda las emisoras que escuchas con frecuencia en Favoritos y configura un temporizador de apagado.
- Consulta la emisora actual y controla la reproducción desde la barra de menús de macOS.
- Elige la apariencia clara, oscura o del sistema; la interfaz está disponible en chino simplificado, chino tradicional, inglés, japonés, coreano, tailandés, español y árabe.
- De forma predeterminada, la reproducción no se inicia automáticamente al abrir la app; puedes cambiarlo en Ajustes.

### Versión y requisitos del sistema

Versión actual: 1.0. Compatible con macOS 15 o posterior; incluye una versión universal para Mac con chip Apple e Intel.
